# Terminal Chat — 终端 + 网页聊天

基于 [antirez/smallchat](https://github.com/antirez/smallchat) 的极简聊天工具: 单文件服务器, 终端和浏览器都能聊, 零第三方依赖。

## 功能

- **双端** — 终端客户端(自定义 UTF-8 行编辑: 方向键/Delete/历史/中文) + 网页端(浏览器打开即用, 手机可用)
- **房间/密码/昵称** — `/join <房间> [密码]` 创建/加入, `/nick` 改昵称, `/rooms`/`/who` 查看
- **历史回放** — 加入房间自动回放最近 20 条, 日志落盘 `./logs/<房间>.log`
- **网页端增强** — 消息时间戳(HH:MM), 昵称彩色(5 色调色板, 同昵称恒同色)
- **轻量** — 服务器单文件 ~1000 行 C, 零依赖, 单进程 select 多路复用

## 架构

```
┌──────────────┐  TCP 7711  ┌──────────────────┐
│ 终端客户端    │ ◄────────► │                  │
│ (ledit 编辑)  │            │   smallchat-server │
└──────────────┘            │   (单文件 C)     │
┌──────────────┐  HTTP 7712 │                  │
│ 浏览器网页    │ ◄────────► │   房间/密码/广播   │
│ (零安装)      │            │   内嵌网页 + SSE  │
└──────────────┘            └──────────────────┘
```

## 编译

```bash
make
```

生成:
- `smallchat-server` — 服务端(终端 + 网页两个端口)
- `smallchat-client` — 终端客户端

## 使用

### 服务器

```bash
./smallchat-server
```
- 终端: `0.0.0.0:7711`
- 网页: `0.0.0.0:7712`(浏览器打开 `http://<服务器IP>:7712`)

### 终端客户端

```bash
./smallchat-client <服务器IP> 7711
```

行编辑支持: 方向键移动光标、Delete 删除、退格(汉字整字删)、Home/End、上下键翻历史、Ctrl-A/E/U/W、Ctrl-D(空行)退出。

### 聊天命令

| 命令 | 说明 |
|------|------|
| `/nick <名字>` | 设置昵称 |
| `/join <房间> [密码]` | 加入房间; 不存在则创建 |
| `/leave` | 离开房间回大厅 |
| `/rooms` | 列出所有房间 |
| `/who` | 当前房间在线用户 |

### 网页端

1. 浏览器打开 `https://<服务器IP>/chat`(注意结尾斜杠; 服务器上先跑过 `deploy-https.sh` 才有 HTTPS)
2. 输入昵称、房间名、密码(可选) → 进入
3. 网页用户和终端用户在同一个房间里互聊

### Windows 用户

用**浏览器**(零安装): 打开 `https://<服务器IP>/chat` 即可聊天。
(旧版可用的 Telnet 方案已废弃: 明文端口 7711 已对公网关闭, 无法直连)

## 部署

- 服务器上编译(源码跨平台, 二进制不通用): `make && ./smallchat-server`
- 安全组: 放行 22 + 443 即可(7711/7712 走 SSH 隧道和 Apache 反代, 不对外)
- 网页加密: `./deploy-https.sh <服务器IP>`(见"加密传输"节)
- 后台运行: `nohup ./smallchat-server > /dev/null 2>&1 &`
- 端口修改: `smallchat-server.c` 里的 `SERVER_PORT` / `WEB_PORT`, 重编译

## 加密传输

默认明文; 要隐私时两条路都**零代码**、用系统自带加密:

- **终端** — SSH 隧道连 7711, 再连本地端口:
  `./tunnel.sh <ssh 目标>`(如 `./tunnel.sh lsm`), 即
  `ssh -fN -L 7711:127.0.0.1:7711 <ssh目标>` 后 `./smallchat-client 127.0.0.1 7711`
- **网页** — 无域名也能加密: 服务器上跑一次 `./deploy-https.sh <服务器IP>`,
  生成自签名证书 + Apache 反代 443→7712, 浏览器打开 `https://<IP>/chat`。
  首次访问点"高级 → 继续"一次; 加密有效, 只是证书不受信任
  (代价: 自签名下浏览器通知不可用, 要通知需域名真证书)

配好后把**安全组收口为只放行 22 + 443**, 关掉 7711/7712 公网直连,
密码和消息就不再裸奔。注意: 关 7711 后 telnet 用户不可用, 用浏览器即可。
网页反代挂 `/chat` 路径, 其余路径反代到 :80 的现有站点 —— 服务器上
http 站的所有页面(含根路径)都能换成 `https://<IP>/<原路径>` 访问;
`/chat` 不带尾斜杠会自动补上(已配重定向)。

## 限制与说明

极简实现的有意取舍:

- **默认明文传输**: 消息和密码无加密(加密方法见上节)。小圈子/信任网络够用, 公网聊敏感内容先走隧道/HTTPS
- **无持久会话**: 服务器重启后房间列表清空, 日志保留
- **网页断线用户保留在册**: SSE 断开后用户仍在在线名单, 刷新页面自动复用
- **日志不轮转**: 长期运行注意 `logs/` 大小
