# Terminal Chat — 终端 + 网页聊天

基于 [antirez/smallchat](https://github.com/antirez/smallchat) 的极简聊天工具: 单文件服务器, 终端和浏览器都能聊, 零第三方依赖。

## 功能

- **双端** — 终端客户端(自定义 UTF-8 行编辑: 方向键/Delete/历史/中文) + 网页端(浏览器打开即用, 手机可用)
- **房间/密码/昵称** — `/join <房间> [密码]` 创建/加入, `/nick` 改昵称, `/rooms`/`/who` 查看
- **历史回放** — 加入房间自动回放最近 20 条, 日志落盘 `./logs/<房间>.log`
- **网页端增强** — 消息时间戳(HH:MM), 昵称彩色(5 色调色板, 同昵称恒同色)
- **轻量** — 服务器单文件 ~1000 行 C, 零依赖, 单进程 select 多路复用

## 架构

```
┌──────────────┐  TCP 7711  ┌──────────────────┐
│ 终端客户端    │ ◄────────► │                  │
│ (ledit 编辑)  │            │   smallchat-server │
└──────────────┘            │   (单文件 C)     │
┌──────────────┐  HTTP 7712 │                  │
│ 浏览器网页    │ ◄────────► │   房间/密码/广播   │
│ (零安装)      │            │   内嵌网页 + SSE  │
└──────────────┘            └──────────────────┘
```

## 编译

```bash
make
```

生成:
- `smallchat-server` — 服务端(终端 + 网页两个端口)
- `smallchat-client` — 终端客户端

## 使用

### 服务器

```bash
./smallchat-server
```
- 终端: `0.0.0.0:7711`
- 网页: `0.0.0.0:7712`(浏览器打开 `http://<服务器IP>:7712`)

### 终端客户端

```bash
./smallchat-client <服务器IP> 7711
```

行编辑支持: 方向键移动光标、Delete 删除、退格(汉字整字删)、Home/End、上下键翻历史、Ctrl-A/E/U/W、Ctrl-D(空行)退出。

### 聊天命令

| 命令 | 说明 |
|------|------|
| `/nick <名字>` | 设置昵称 |
| `/join <房间> [密码]` | 加入房间; 不存在则创建 |
| `/leave` | 离开房间回大厅 |
| `/rooms` | 列出所有房间 |
| `/who` | 当前房间在线用户 |

### 网页端

1. 浏览器打开 `http://<服务器IP>:7712`
2. 输入昵称、房间名、密码(可选) → 进入
3. 网页用户和终端用户在同一个房间里互聊

## 部署

- 服务器上编译(源码跨平台, 二进制不通用): `make && ./smallchat-server`
- 需放行 TCP 7711、7712(云服务器在安全组配置)
- 后台运行: `nohup ./smallchat-server > /dev/null 2>&1 &`
- 端口修改: `smallchat-server.c` 里的 `SERVER_PORT` / `WEB_PORT`, 重编译

## 限制与说明

极简实现的有意取舍:

- **明文传输**: 消息和密码无加密。小圈子/信任网络够用, 公网不建议聊敏感内容
- **无持久会话**: 服务器重启后房间列表清空, 日志保留
- **网页断线用户保留在册**: SSE 断开后用户仍在在线名单, 刷新页面自动复用
- **日志不轮转**: 长期运行注意 `logs/` 大小
